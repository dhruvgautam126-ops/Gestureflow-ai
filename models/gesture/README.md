- File: `gesture_recognizer.task`
- Source: Google MediaPipe Gesture Recognizer, FP16 bundle version 1

- SHA-256: `97952348cf6a6a4915c2ea1496b4b37ebabc50cbbf80571435643c455f2b0482`
- Model license: Apache-2.0

The bundle includes palm detection, 21-point hand landmarks, and a gesture
classifier. GestureFlow AI uses the `Open_Palm`, `Closed_Fist`, and `Thumb_Up`
categories. The app supports up to four tracked hands.

Gesture labels are visual indicators for this prototype. They are not a
standalone safety or emergency signal.
